# 09 - Quantum Optimization

**Level:** Advanced

## Overview
This folder explores quantum optimization algorithms for combinatorial optimization problems using Qiskit and hybrid quantum-classical methods.

The experiments focus on mapping optimization problems to quantum Hamiltonians and solving small-scale instances using variational quantum circuits.

## Topics Covered
- Classical combinatorial optimization
- Quadratic Unconstrained Binary Optimization (QUBO)
- Ising models and cost Hamiltonians
- Quantum Approximate Optimization Algorithm (QAOA)
- Max-Cut problems
- Graph partitioning
- Community detection as an optimization problem
- Classical versus quantum optimization

## Learning Outcomes
- Formulate optimization problems using QUBO and Ising models.
- Construct cost and mixer circuits for QAOA.
- Apply optimization techniques to graph-based problems.
- Compare quantum optimization results with classical methods.

## Jupyter Notebook Experiments
Notebooks will include QAOA demonstrations, Max-Cut examples, graph optimization experiments, and performance comparisons.
