# 07 - Grover's Algorithm and Quantum Search

**Level:** Intermediate

## Overview
This folder explores Grover's quantum search algorithm and amplitude amplification through mathematical derivations, circuit construction, and Qiskit simulations.

The experiments demonstrate how phase oracles and diffusion operators increase the probability of measuring marked solutions.

## Topics Covered
- Unstructured search problems
- Quantum search oracles
- Phase inversion
- Grover diffusion operator
- Amplitude amplification
- Grover iteration
- Optimal number of iterations
- Multiple marked states

## Learning Outcomes
- Construct phase oracles for marked search states.
- Implement the Grover diffusion operator.
- Analyze amplitude amplification mathematically.
- Execute Grover circuits and interpret measurement results.

## Jupyter Notebook Experiments
Planned notebooks include two-qubit and three-qubit search examples, oracle construction, and search probability analysis.
