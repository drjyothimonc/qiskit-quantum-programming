# 05 - Basic Quantum Algorithms

**Level:** Intermediate

## Overview
This folder introduces foundational quantum algorithms that demonstrate quantum interference, superposition, phase kickback, and quantum query advantages.

Each algorithm will be implemented using Qiskit with mathematical explanations, circuit diagrams, simulation results, and comparisons with classical approaches.

## Topics Covered
- Quantum oracle models
- Phase kickback
- Deutsch algorithm
- Deutsch-Jozsa algorithm
- Bernstein-Vazirani algorithm
- Simon's algorithm
- Quantum interference

## Learning Outcomes
- Understand the problems addressed by foundational quantum algorithms.
- Design quantum oracles for specific functions.
- Implement and simulate quantum algorithms using Qiskit.
- Interpret how quantum interference reveals information about functions.

## Jupyter Notebook Experiments
The planned notebooks will include complete algorithm implementations, quantum state evolution, circuit visualizations, and result analysis.
