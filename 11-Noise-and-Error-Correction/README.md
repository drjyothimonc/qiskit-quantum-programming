# 11 - Quantum Noise and Error Correction

**Level:** Advanced

## Overview
This folder introduces quantum noise, decoherence, noisy quantum circuit simulation, and fundamental quantum error correction techniques using Qiskit.

The experiments examine how noise affects quantum states and computations and how error detection, correction, and mitigation methods can improve the reliability of quantum computation.

## Topics Covered
- Quantum noise and decoherence
- Bit-flip and phase-flip errors
- Depolarizing and amplitude damping channels
- Kraus operator representations
- Noisy circuit simulation
- Three-qubit repetition codes
- Quantum error syndromes
- Introduction to error mitigation

## Learning Outcomes
- Model common quantum noise channels.
- Simulate noisy quantum circuits.
- Analyze noise effects on quantum measurements.
- Implement simple error detection and correction circuits.
- Compare ideal and noisy simulation outcomes.

## Jupyter Notebook Experiments
Notebooks will include noise model demonstrations, noisy Bell states, repetition-code experiments, and error analysis.
